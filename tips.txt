In order to run streamlit(app.py):
_ activate the virtual Environment : .\.venv\Scripts\activate
_ run the app : python -m streamlit run src/app.py

===> First thing First, in order to run the whole project you must download the requirement dependecies:

    pip install -r requirements.txt


This is the src folder flow:
---
## 🧠 Your `src/` Folder: Detailed Guide
### 1. 📄 `app.py` — **Streamlit UI**
This is the **main entry point** of your app. It handles:
- Uploading files
- Displaying extracted text
- Accepting user questions
- Showing answers or triggering workflows

**What to do here:**
- Import functions from other folders
- Build the Streamlit interface
- Call processing and ML functions based on user actions
---
### 2. 📂 `document_processing/` — **File Handling & OCR**
    This folder contains all logic for reading documents and extracting text.

#### `pdf_utils.py`
    - Function to extract text from PDF using PyMuPDF
    function:    def extract_text_from_pdf(file_stream): ...

#### `ocr_utils.py`
    - Function to extract text from images using Tesseract
    Function: extract_text_from_image(image_path): ...

#### `docx_writer.py`
    - Function to save extracted or processed text to a `.docx` file
    function: def save_text_to_docx(text, filename): ...

---
### 3. 📂 `ml_engine/` — **Machine Learning & NLP**
    This folder handles all ML and Q&A logic.

#### `preprocess.py`
- Clean and tokenize text
- Convert text to vectors (e.g., TF-IDF)

#### `model.py`
- Load and apply ML models (e.g., classification, clustering)

#### `qa_pipeline.py`
- Use a Q&A model (e.g., HuggingFace Transformers) to answer questions
    function: def answer_question(question, context): ...

---
### 4. 📂 `workflow/` — **Automation & Logic**
    This folder manages document workflows like tagging, summarization, etc.
#### `workflow_manager.py`
    - Logic to trigger workflows based on document type or user input
    function: def run_workflow(document_text): ...

---
### 5. ⚙️ `config.py` — **Settings**
Central place to store:
- File paths
- Model settings
- API keys (if needed)

    PDF_FOLDER = "data/"
    MODEL_PATH = "models/my_model.pkl"
---
## 🔄 How Everything Connects

User uploads file → app.py
    ↓
app.py calls → document_processing.pdf_utils.extract_text_from_pdf()
    ↓
Text is displayed → app.py
    ↓
User asks question → app.py calls ml_engine.qa_pipeline.answer_question()
    ↓
Answer is shown → app.py

---
This is also the flow of the project:

User uploads PDF → Extract text (PyPDF or OCR)
    ↓
Preprocess text → spaCy/NLTK
    ↓
User asks question → transformers Q&A model
    ↓
User clicks summarize → transformers summarization model
    ↓
Save results → python-docx
    ↓
Display in Streamlit
