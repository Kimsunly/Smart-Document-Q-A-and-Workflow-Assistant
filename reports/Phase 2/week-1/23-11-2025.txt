2. OCR Overview

OCR (Optical Character Recognition) is a technology used to convert text in images or scanned documents into editable and searchable digital text. In the context of the Smart Document project, OCR is crucial for extracting text from uploaded files, including scanned PDFs or photos of documents.

Key Points Learned:
- OCR is essential for digitizing information from non-digital sources.
- Accuracy depends on image quality; blurry, noisy, or skewed images can reduce performance.
- Preprocessing with OpenCV can enhance OCR results by improving image contrast and clarity.

3. Tools and Installation

Code Snippet Example:
import cv2
from PIL import Image
import pytesseract

pytesseract.pytesseract.tesseract_cmd = r"C:\Program Files\Tesseract-OCR\tesseract.exe"

# Load and preprocess image
img = cv2.imread("sample.png")
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
thresh = cv2.threshold(gray, 150, 255, cv2.THRESH_BINARY)[1]

# Save preprocessed image
cv2.imwrite("cleaned.png", thresh)

# OCR extraction
text = pytesseract.image_to_string(thresh)
print(text)
